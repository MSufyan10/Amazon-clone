# Amazon Clone - Educational Project

> **Live Demo:** https://amazon-clone-ms-ufyan10.vercel.app

> **GitHub Pages:** MSufyan10/Amazon-clone

### ⚠️ Disclaimer
This is an **educational UI clone** built for learning purposes only. It is **NOT the real Amazon.com**. Not affiliated with Amazon.com, Inc. No real transactions, no user data collection, no payments.

### 📸 Preview
Responsive Amazon-inspired e-commerce homepage with navigation bar, hero banner, and product categories.

### ✨ Features
- Amazon-style navigation bar with logo, location, search, and cart
- Hero banner section
- Product category cards (8 boxes: Clothes, Health & Personal Care, Furniture, Electronics, Beauty, Pet Care, Toys, Fashion)
- Fully responsive layout - 2 products per row on mobile
- Hover effects and modern UI
- Deployed on Vercel & GitHub Pages

### 🛠️ Tech Stack
- **HTML** - Page structure
- **CSS** - Styling, Flexbox, Media Queries
- **Vercel** - Hosting
- **GitHub Pages** - Alternative hosting
